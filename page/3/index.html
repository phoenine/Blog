如何在Notion中获取随机数
发表于2025-05-20|更新于2026-07-21|常用工具Notion
Notion公式本身不支持直接生成随机数，但可通过组合 id()、timestamp()、now() 等内置函数与算术运算实现。常用方法包括：1）动态随机数——使用 id() 与 now() 的混合公式，页面刷新时数值变化；2）静态随机数——结合 Created time 与 id()，生成一次性不变的数值；3）每日随机数——将 Created time 与 now() 的天数差取模，保证每天更新一次。通过这些公式，可在数据库中实现洗牌、随机推荐或每日提示等功能。
